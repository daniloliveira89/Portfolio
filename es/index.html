Trayectoria & Filosofía

Construyendo software veloz, resiliente y enfocado en la experiencia.

Acredito que o bom software é aquele que combina rigor arquitetural com delight visual. Cada projeto que construo — seja um card game cyberpunk com árvores de decisão em TypeScript ou um observatório global de inteligência artificial atualizado automaticamente via GitHub Actions — nasce para resolver um problema real sem complexidade desnecessária.

Minha abordagem prioriza ferramentas modernas, arquiteturas serverless (como Cloudflare Workers) e ecossistemas abertos para entregar tempos de resposta instantâneos e custo de infraestrutura próximo a zero.

01. Rendimiento

Zero bloatware, carregamento instantâneo e código limpo.

02. Autonomía

Pipelines automatizados sem dependência de servidores caros.

03. Usabilidad

Interfaces intuitivas, responsivas e visualmente imersivas.
