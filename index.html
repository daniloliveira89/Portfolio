Hospedagem 100% Gratuita e Sem Complicação

Este site foi construído com arquitetura estática pura, leve e ultra-rápida. Já configurei todos os arquivos necessários para você colocá-lo no ar em segundos:

Arquivo vercel.json pronto. Basta importar o repositório na Vercel e o deploy é imediato com HTTPS automático.

Netlify

Arquivo netlify.toml configurado. Suporta drag-and-drop da pasta ou conexão direta com o Git.

GitHub Pages

Workflow deploy.yml pronto. Basta subir para o repositório que o site publica automaticamente.
